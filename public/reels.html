App credentials & setup instructions
Paste, then Save keys to .env at the top of the page. Redirect URIs to register: , , and .
YouTube (once): console.cloud.google.com → new project → APIs & Services → Library: enable YouTube Data API v3 and YouTube Analytics API → OAuth consent screen: External, add your Google account as a test user → Credentials → Create → OAuth client ID → Web application, authorised redirect URI = the YouTube redirect above → copy the client ID and secret here → Connect YouTube and approve.
Heads-up: until the project passes Google's API compliance audit, every upload is locked private. Publish as private, then request the audit (YouTube API Services → compliance) — or use YouTube Studio for public Shorts until then.

Facebook & Instagram (once): developers.facebook.com → Create app → Business → add Facebook Login → Settings → Valid OAuth Redirect URIs = the Meta redirect above → App settings → Basic: copy App ID and App Secret here. Make sure your Instagram is a professional account linked to your Facebook Page (Meta Business Suite → Settings → Instagram). In Development mode you (an app admin) can publish to your own Pages without App Review. Connect Facebook / Instagram, tick all permissions, pick the Page.

TikTok (once): developers.tiktok.com → Create app → add Login Kit and Content Posting API → Redirect URI = the TikTok redirect above → copy Client Key and Client Secret here → Connect TikTok and approve.
Heads-up: until TikTok app review is completed, posts default to Self Only (Private). Once approved, public posting is unlocked.

Analytics

Views, average watch time and (where the platform gives it) the retention curve — how much of the audience is still watching at each point. A curve that drops in the first 2–3 seconds means the hook, not the story.

Video per scene: pick/cut a different video clip for each scene.
Finish video then use another one if needed: play clip continuously across scenes until finished, then move to another clip.

Every scene is cut from a clip in stock/ — no image provider, nothing billed. The pipeline picks the clip whose file name best matches the scene's keywords (and narration), never reuses one within a reel, and starts somewhere inside long clips rather than always at the top. Name files by what they show: ocean-waves-sunset.mp4, city-night-traffic.mp4. Free, copyright-free footage: Pexels, Pixabay, Mixkit, Coverr. Any length or aspect works — short clips are slowed or ping-ponged, wide ones are cropped. Tick clips to make a shortlist for this reel: auto-pick then chooses only among the ticked ones.

Batch render

Queue many reels and let them render one after another — overnight, or while you work on something else. How: load a bundle (e.g. content/60-days-all.json) → tick the days → Queue selected. Renders use the provider settings above as they are right now; the queue survives a server restart.
