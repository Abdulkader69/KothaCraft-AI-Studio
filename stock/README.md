# Footage library

Drop free, copyright-free video clips here (or upload them from the **Local video**
page). A project with `"footage": "stock"` cuts every scene from these instead of
generating images.

**Name files by what they show** — the picker matches words in the file name against
each scene's keywords and narration:

    ocean-waves-sunset.mp4
    forest-fog-morning.mp4
    city-night-traffic.mp4
    nature/mountain-snow-peak.mp4      ← subfolder names count as words too

Any length or aspect works: long clips are trimmed (starting somewhere inside, not
always at the top), short ones are slowed or ping-ponged, wide ones are cropped to
the reel's frame. Audio is dropped.

Free sources: Pexels, Pixabay, Mixkit, Coverr — all allow commercial use without
attribution. `.thumbs/` is generated by the UI and safe to delete.
